# Демонстрационная версия сайта Филиала МГУ в Сарове

Статичный снимок публичной части сайта для просмотра. В репозитории нет базы данных, административной панели, паролей, конфигурации сервера и документов.

Для обновления снимка при запущенном локальном сайте выполните:

```bash
node tools/export-static-site.mjs
```

GitHub Pages публикует содержимое папки `docs`.
